# 小程序后端接入

小程序现已使用本项目 Node.js 后端，所有查车、线路、公告、登录、收藏、失物、反馈和司机作业通过统一请求层访问接口，语音也从同一后端读取。当前运行的是本地演示环境，正式 AppID 为 wxce7099e8a1d160ed。

## 当前连接地址

| 运行方式 | API |
| --- | --- |
| 本机微信开发工具 | http://127.0.0.1:3100/api |
| 同一 Wi-Fi 下的手机 | http://<电脑当前局域网IP>:3100/api |
| 手机浏览器看网页演示 | http://<电脑当前局域网IP>:3100/（后端内置构建产物） |
| 正式版和体验版 | 需配置真实 HTTPS 地址，目前未部署 |

地址不要手写死。运行 `npm run demo:phone` 会检测当前私有 IPv4（优先 `en0`），写入小程序配置和 `.env`，启动后端并从本机、局域网分别请求 `/api/health` 自检。电脑换了网络后重新运行一次即可。后端启动时也会自动监听当前所有私有网卡地址，不再依赖 `.env` 里的旧 IP。

小程序通过运行平台自动选择地址：开发工具使用本机回环；手机使用电脑局域网地址，并带候选地址自动重试。请保持电脑后端运行，并确保手机和电脑在同一 Wi-Fi。微信或系统若弹出本地网络访问提示，请在手机端允许。当前代码不申请用户位置权限。

`miniprogram/config.runtime.js` 保存公开接口地址（含 `deviceApiCandidates` 候选列表）。`miniprogram/config.js` 负责区分开发版、体验版和正式版，正式/体验版不使用局域网配置，也不读取开发时手动填写的地址。后端切换时清除旧登录会话，避免把原服务器的登录凭证发送到新服务器。

## 启动和更新地址

```bash
npm run demo:phone
```

这一个命令会：

1. 运行 `mini:connect`，写入当前局域网地址、候选地址和端口；
2. 如果后端没运行则启动后端，否则检查它是否监听了当前地址；
3. 打印手机浏览器自测地址。**手机浏览器能打开并看到 `{"ok":true,"demo":true}`，才说明网络层通了。**

也可以分开执行：

```bash
npm run mini:connect -- --lan
npm run dev
```

`mini:connect` 自动选择本机私有 IPv4，更新小程序的设备地址和 `.env` 的 `LIAN_LAN_IP`，仅对本项目 `project.private.config.json` 设置本地开发 `urlCheck:false`。共享项目配置中的 `urlCheck:true` 保留，正式运行仍要求 HTTPS 合法域名。此设置用于开发工具连接本机/局域网 HTTP，不会修改微信后台或全局工具安全设置。

如果有多个网络接口，可指定：

```bash
npm run mini:connect -- --lan --ip 192.168.31.164
```

地址变化后重启后端并重新编译小程序。“我的”页面下方开发专用的“后端连接”区域可查看/修改接口地址、候选地址并检测连接，也可以点“恢复默认地址”清除手工地址。该区域不会出现在体验版或正式版。

## 手机连不上时的判定顺序

1. 手机浏览器打开终端打印的 `/api/health` 地址。打不开就是网络问题：确认同一路由器、后端终端没关、电脑防火墙未拦截 3100。
2. 电脑连手机热点、手机又走蜂窝网络时，iOS 热点主机常常访问不到热点客户端。请换成一个独立 Wi-Fi 路由器，让电脑和手机都连它。
3. 浏览器能打开但小程序不行：手机微信右上角“…”→“开发调试”打开后重进；iPhone 在“设置→微信→本地网络”允许访问；再重新编译。
4. 仍提示域名校验：确认 `project.private.config.json` 的 `urlCheck` 为 `false`，并重新扫码真机调试。
5. 必须跨网络演示时可运行 `npm run demo:tunnel`，它使用 cloudflared 生成临时 HTTPS 地址并自动写入小程序配置；当前网络若屏蔽 `trycloudflare.com`，脚本会自检失败并明确提示。

## 只看演示界面（不经过小程序）

手机浏览器直接打开后端根地址，例如 `http://172.20.10.12:3100/`。后端会把 `dist/` 中构建好的网页版演示和 `/api` 一起提供，无需另开服务。

需要改代码后热更新时：

```bash
npm run demo:web
```

手机浏览器打开 `http://<电脑局域网IP>:5180`，API 由 Vite 代理到本机后端。

## 正式部署时切换

```bash
npm run mini:connect -- --url https://你的正式域名/api
```

该命令只更新正式 HTTPS 地址，不部署服务器，也不修改微信公众平台。还需在服务器配置微信 AppSecret、管理员和司机凭据，关闭演示模式，配置 HTTPS 反向代理，并在微信后台添加 request 合法域名。正式师生使用微信登录，当前演示师生登录会保存到本地后端数据库。

## 导航图标

底栏“出行、线路、服务、我的”已配置普通和选中两种颜色。原生底栏使用81×81透明 PNG，文件均小于40KB；同目录保留 SVG 源图方便后续修改。地图站点标记也有独立图标和明确尺寸。

```bash
npm run icons:mini
```

素材目录：`miniprogram/assets/tabbar/`。生成脚本：`scripts/make-tabbar-icons.mjs`。图标路径已经写入 app.json，不需要安装额外小程序依赖。
