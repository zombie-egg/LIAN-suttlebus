# 接口说明

API 前缀 `/api`，JSON 请求和响应。需要登录的接口使用 `Authorization: Bearer <token>`。错误响应 `{ "error": "原因" }`，分别使用 400 输入无效、401 未登录、403 无权限、404 不存在、409 资料被引用、429 请求过频、503 外部能力未配置。生产反向代理必须启用 HTTPS。

| 方法和路径 | 权限 | 功能 |
| --- | --- | --- |
| GET /health | 公开 | 服务与演示状态 |
| GET /public | 公开 | 线路、站点、车辆脱敏数据、按站点 ETA、公告和审核后的失物公开字段 |
| GET /audio/:name | 公开 | 固定中英 WAV 素材 |
| POST /login | 演示或员工凭据 | `{role, password?, driverId?, demoIdentity?}`；生产禁止此入口登录师生 |
| POST /wx-login | 微信 code | `{code}`；服务端换取 openid，创建师生会话 |
| POST /logout | 登录 | 注销当前服务端会话 |
| GET /me | 登录 | 本人的收藏、反馈、失物提交及认领记录 |
| POST /favorites | 登录 | `{routeId}`，切换收藏 |
| POST /feedback | 登录 | `{title,content,place?}` |
| POST /lost | 登录 | `{title,content,place?}`；默认待审核，不公开 |
| POST /claims | 登录 | `{lostId,title,content}`；只允许申请认领已发布物品 |
| POST /reports | 司机或管理员 | `{title,content,vehicleId}`；司机仅可上报自己的车辆 |
| GET /driver | 司机 | 本人的车辆、任务和上报记录 |
| PATCH /tasks/:id | 本人司机或管理员 | `{status}`：pending → accepted → completed |
| POST /telemetry | X-Device-Key | 设备定位；字段见 README |
| GET /admin | 管理员 | 所有业务资料、统计及审计记录 |
| GET /admin/export | 管理员 | UTF-8 BOM CSV |
| PUT /admin/:kind/:id | 管理员 | 创建或更新 stations/routes/vehicles/drivers/tasks/notices |
| DELETE /admin/:kind/:id | 管理员 | 删除基础资料；被引用时返回409 |
| PATCH /admin/:kind/:id | 管理员 | 处理 lost/feedback/claims/reports；包含 `{status,reply?}` |
| POST /demo/refresh | 演示管理员 | 刷新示例车辆定位时间，不修改真实环境 |

失物发布时还必须传 publicTitle、publicContent；可传 publicPlace、en、contentEn。公开接口只返回审核后的公开描述，不直接公开用户提交的私有原文、认领内容或联系方式。其他记录的回复只对本人和管理员可见。

任务正文 title、en，必须关联已有 driverId、vehicleId、routeId，并且车辆绑定与任务一致。date 使用 YYYY-MM-DD，北京时间；time 使用 HH:mm。不可通过修改资料接口跳过司机确认状态。

线路使用站点ID数组 stations 表示方向顺序，首末班 first/last 为 HH:mm，interval 为整分钟，enabled 为布尔值。环线首尾为同一站点；非环线不绕回预测。中英文名称必须同时填写。当前不支持跨零点班次。

终端建议5～10秒上报，90秒无更新判为断流。统一入口支持经纬度和速度，不包含供应商二进制协议解析。生产统计和审计采用一期单实例存储；大规模设备接入前需拆分状态表与时间序列、限流与归档。
