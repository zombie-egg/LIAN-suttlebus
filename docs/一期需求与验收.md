# 黎安一站式一期需求与验收

本项目依据工作区内《关于建设黎安国际教育创新试验区公共出行数字化服务平台的必要性分析及一期建设方案》开发。一期建设目标是对现有公共摆渡车服务做数字化升级，保留公益属性，不引入支付、售票、新增运力或商业经营。

交付包括原生微信小程序、React 管理后台与师生体验页、Node.js API、SQLite 持久化、双语语音素材及测试。AppID 为 wxce7099e8a1d160ed。原始需求没有提供运营实数，内置资料全部为演示数据；正式模式使用独立的空数据库，必须由运营方录入。

## 数据及权限

师生可以不登录查车、看线路和公告，登录后收藏、提交及查看个人记录。司机只能读取本人任务、车辆和上报记录，只能上报本人绑定车辆。管理员可以维护基础资料、发布任务、处理服务记录及导出统计。生产环境司机使用按编号独立配置的凭据，管理员凭据来自环境变量，师生身份从微信服务端换取。会话24小时过期，退出会使服务端会话失效。演示模式的免密身份只用于本机体验。

公开接口不返回司机编号、终端编号、反馈内容或认领私有信息。线路中的站点顺序决定行进方向，环线首尾填写同一个站点。坐标必须统一为 GCJ-02。终端时间戳应为毫秒，拒绝重复、乱序、超前及过旧上报。定位断流时停止显示可靠预测并在后台告警。终端原始 WGS-84 坐标需要在供应商接入层统一转换，避免地图偏移。

## 试运营验收清单

1. 管理方确认车辆清单、司机编号、线路方向、站点坐标、首末班、班次间隔及中英文名称。
2. 部署生产服务，录入基础资料，为每台终端绑定唯一 deviceId。
3. 至少两台真实设备连续上报，核对原生地图点位、轨迹方向和断流预警。
4. 用微信 iOS/Android 真机分别验证登录、音频、静音场景、地图、到站提醒、前后台切换、弱网及恢复。
5. 完整走一遍收藏、反馈处理、失物审核、认领申请、司机任务确认、异常上报及CSV导出。
6. 实车采集至少高峰和平峰各一轮到站数据，校准估算误差与提醒阈值。
7. 运营方完成隐私说明、数据保存期限和管理员交接，备份数据库，提交微信体验版及审核。
